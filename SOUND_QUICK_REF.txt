TL;DR - Golden Rules
════════════════════════════════════════════════════════════════════

  ✓ Bit Depth:        16-bit PCM WAV
  ✓ Sample Rate:      8000 Hz or 44100 Hz
  ✓ Channels:         Mono (preferred) or Stereo
  ✓ Duration:         0.5–2 seconds
  ✓ Peak Level:       -6 to -3 dB (NO clipping)
  ✓ RMS Level:        -18 to -15 dB
  ✓ Tone:             UI/game sound (sharp, clear, 500 Hz–8 kHz focus)

Killer Sound Checklist
────────────────────────────────────────────────────────────────────

  □ Starts quickly (trim silence at beginning & end)
  □ 0.5–2 seconds long
  □ Peak level at -3 to -6 dB (visual waveform)
  □ No digital clipping or distortion
  □ Sounds punchy and clear
  □ Fits CoD4 sci-fi / military vibe
  □ Matches loudness of reference.wav
  □ 16-bit, 8000+ Hz sample rate
  □ Mono or Stereo WAV format

Loudness Sweet Spot
────────────────────────────────────────────────────────────────────

  Target Peak:    -3 dB
  Acceptable:     -6 dB to -3 dB
  Too Loud:       ≥ 0 dB (clipping/distortion) ✗
  Too Quiet:      ≤ -10 dB ✗

════════════════════════════════════════════════════════════════════

Comparison Workflow (Use Reference Sound)
────────────────────────────────────────────────────────────────────

  1. Open scriptdata/streaksounds/reference.wav in your DAW
  2. Load your custom sound in another track
  3. Compare waveform amplitude visually (should be similar)
  4. Use meter/analyzer: peak = -3 to -6 dB, RMS = -18 to -15 dB
  5. Listen: Does your sound match the tone/clarity of reference?
  6. Iterate: Adjust EQ/levels until they're similar
  7. Export: Save as WAV (16-bit, 44100 Hz)

════════════════════════════════════════════════════════════════════

Installation Workflow
────────────────────────────────────────────────────────────────────

  1. Create your sound file (following specs above)
  2. Copy to: mods/gungame/scriptdata/streaksounds/<name>.wav
  3. Run: build-streak-sounds.ps1
  4. Rebuild: zonebuilder (buildzone mod)
  5. Test: Start server with fs_game mods/gungame
