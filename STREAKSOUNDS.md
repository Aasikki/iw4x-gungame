# Killstreak Sounds Guide

## Overview

The mod supports custom audio for each killstreak. When a player earns a killstreak, a sound plays to that player if:
1. A `.wav` file exists in `scriptdata/streaksounds/`
2. The corresponding sound alias is built into `mod.ff`

Missing files are silently skipped, so you can add sounds incrementally.

## Adding Sounds

### Step 1: Prepare Audio Files

Create 16-bit PCM `.wav` files (mono works best) for the streaks you want. File names:

| Killstreak | Filename |
|---|---|
| Riotshield | `riotshield.wav` |
| No Recoil | `norecoil.wav` |
| Speed | `speed.wav` |
| Gl Sentry | `glsentry.wav` |
| Suicide Bomber | `suicidebomber.wav` |
| Jetpack | `jetpack.wav` |
| Bomber | `bomber.wav` |
| I.M.S | `ims.wav` |
| Juggernaut | `juggernaut.wav` |
| Explosive Bullets | `explosivebullets.wav` |
| Radioactive | `radioactive.wav` |
| XRay | `xray.wav` |
| Godmode | `godmode.wav` |

Place them in: `mods/gungame/scriptdata/streaksounds/`

### Step 2: Get a Template (First Time Only)

1. Start `zonebuilder.exe` from your game folder
2. In the console, type: `dumpzone common_mp`
3. Find a UI sound in `userraw/dump/common_mp/sounds/` with `"type": 1`
   - `c4_bounce_default.json` is a good example
4. Save it somewhere (e.g., `C:\template.json`)

### Step 3: Build Zone Files

1. Open PowerShell
2. Run:
   ```powershell
   cd C:\your\mod\folder
   .\tools\build-streak-sounds.ps1 `
     -Template "C:\template.json" `
     -ModFolder (pwd) `
     -GameDir "C:\Programs\IW4X server"
   ```

This script:
- Copies each `.wav` to `loaded_sound/` (server location)
- Creates a `.json` sound alias for each in `sounds/`
- Writes `zone_source/mod.csv` in the game folder

### Step 4: Compile with ZoneBuilder

1. Start `zonebuilder.exe`
2. Type: `buildzone mod`
3. Wait for completion. Output: `zonebuilder_out/mod.ff` (~1.4 MB)
4. Copy it to your server's mod folder:
   ```powershell
   copy "C:\Programs\IW4X server\zonebuilder_out\mod.ff" `
        "C:\Programs\IW4X server\mods\gungame\mod.ff"
   ```

Players download `mod.ff` automatically on join.

## How It Works (Code)

**GSC** (`maps/mp/gametypes/killstreaks.gsc`):
- `giveStreak(streak)` now calls `playStreakSound(streak)` 
- `playStreakSound()` checks if `streaksounds/<id>.wav` exists
- If yes, plays sound alias `gg_streak_<id>`
- If no, silently skips

**ZoneBuilder** (`zone_source/mod.csv`):
```
require,common_mp
sound,gg_streak_riotshield
sound,gg_streak_speed
...
```

Each `sound,gg_streak_<name>` line references a `.json` in `sounds/` that points to the `.wav` in `loaded_sound/`.

## Troubleshooting

| Error | Cause | Fix |
|---|---|---|
| "Could not find sound alias" | `.wav` exists but alias not in `mod.ff` | Rebuild mod.ff and restart server |
| Sound doesn't play | `.wav` file missing | Add it to `scriptdata/streaksounds/` and rebuild |
| Script error loading JSON | Malformed `.json` | Check spacing, type field, soundFile path |
| "Unable to load CSV" | `zone_source/mod.csv` not found or wrong name | Run build script with correct `-GameDir` |

## File Structure

```
mods/gungame/
├── mod.ff                           (built by zonebuilder, ~1.4 MB)
├── scripts/
│   ├── settings.gsc
│   ├── core.gsc
│   ├── spawnsystem.gsc
│   └── ...
├── maps/mp/gametypes/
│   ├── killstreaks.gsc              (calls playStreakSound)
│   └── ...
├── scriptdata/
│   └── streaksounds/
│       ├── README.txt
│       ├── speed.wav                (user adds)
│       ├── xray.wav                 (user adds)
│       └── ...
└── tools/
    └── build-streak-sounds.ps1      (helper script)

zone_source/
└── mod.csv                          (auto-generated by build script)

sounds/                              (auto-generated by build script)
├── gg_streak_speed.json
├── gg_streak_xray.json
└── ...

loaded_sound/                        (auto-generated by build script)
├── gg_streak_speed.wav
├── gg_streak_xray.wav
└── ...
```

## Maintenance

- **Always rebuild `mod.ff`** after adding/removing `.wav` files
- The script only includes sounds for files that exist
- Old JSON and WAV files in `sounds/` and `loaded_sound/` don't hurt, but you can delete them before rebuilding
- `zone_source/mod.csv` is auto-generated each run; don't edit it manually
